# Cole Dot Dev Project Estimator

The cole.dev Project Estimator helps prospective clients turn a software idea into a project brief that cole.dev can use to start a scoping conversation.

- **Describe the project.** Choose a project type, such as automation or a custom web app, then answer tailored questions about the problem, users, features, integrations, and timeline.
- **Review the assessment.** Get a project summary, suggested features, a Low, Medium, or High complexity rating, possible development phases, and questions to clarify. Pricing and delivery dates are determined after discovery.
- **Share the brief.** Add your contact details, download the brief, and use **Email cole.dev** to open a draft. Attach the brief and send it from your email app.
